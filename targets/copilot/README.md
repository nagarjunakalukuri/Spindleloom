# GitHub Copilot bundle

Generated by `build_harness_artifacts.py`. Copy `.github/`, `.vscode/`, `.claude/`, `mcp/`, `tools/` and `templates/` into your repo root (`tools/` + `templates/` are the CLI and what it writes from). Chat modes + `copilot-instructions.md` carry the fleet; `.github/prompts/` carries the slash commands; `.claude/skills/` is auto-read by Copilot; `.vscode/mcp.json` registers the live traceability server, launched via `uv run` (install [uv](https://docs.astral.sh/uv/); it provisions the MCP SDK on first run).

## Command line (`sloom`)

`tools/` ships the toolkit CLI that the agent definitions call -- stdlib-only Python 3.10+, no install:

```
python tools/sloom.py check <repo>        # spec battery (reqs, RTM, registry, drift)
python tools/sloom.py run status <run-id> # the distributed run ledger
python tools/sloom.py approve <phase> ... # phase-boundary acceptance token
python tools/sloom.py signoff <gate> ...  # evidence-required release sign-off
python tools/sloom.py flags <repo>        # open FLAG(owner) re-work
```

`sloom scaffold <repo>` lays down the governed docs tree. Run `python tools/sloom.py` with no arguments for the full command list.
