# Windsurf bundle

Generated by `build_harness_artifacts.py`. Copy `.windsurf/`, `.claude/`, `mcp/`, `tools/` and `templates/` into your repo root (`tools/` + `templates/` are the CLI and what it writes from). Windsurf has no subagents, so each role is a `model_decision` rule (activates when relevant); `000-spindleloom-conventions.md` is always-on. Oversize roles are auto-condensed to Windsurf's ~12k rule cap (full text stays in the source/plugin). `.windsurf/workflows/` carries the slash commands; `.claude/skills/` is auto-read by Windsurf.

## Live traceability (MCP)

Windsurf's MCP config is **user-global**, so add this to `~/.codeium/windsurf/mcp_config.json` (install [uv](https://docs.astral.sh/uv/) — it provisions the MCP SDK on first run), with absolute paths to where you copied `mcp/`:

```json
{
  "mcpServers": {
    "sloom": {
      "command": "uv",
      "args": [
        "run",
        "--with",
        "mcp[cli]>=1.2,<2",
        "python",
        "/abs/path/to/your/repo/mcp/mcp_server.py"
      ],
      "env": {
        "SPINDLELOOM_SPEC_ROOT": "/abs/path/to/your/repo"
      }
    }
  }
}
```

## Command line (`sloom`)

`tools/` ships the toolkit CLI that the agent definitions call -- stdlib-only Python 3.10+, no install:

```
python tools/sloom.py check <repo>        # spec battery (reqs, RTM, registry, drift)
python tools/sloom.py run status <run-id> # the distributed run ledger
python tools/sloom.py approve <phase> ... # phase-boundary acceptance token
python tools/sloom.py signoff <gate> ...  # evidence-required release sign-off
python tools/sloom.py flags <repo>        # open FLAG(owner) re-work
```

`sloom scaffold <repo>` lays down the governed docs tree. Run `python tools/sloom.py` with no arguments for the full command list.
